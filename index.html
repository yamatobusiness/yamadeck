Features

運用に必要なものを、ぜんぶ。

アカウントが増えるほど面倒になる作業を、まとめて片づけます。

ワンクリックで切り替え

アカウントごとに独立したブラウザで、ログイン状態を保ったまま一瞬で切り替え。タブやブックマークも使えます。

グループで整理

用途ごとにグループ分け。色やアイコン、メモで見分けやすく。CSV でまとめて取り込み・書き出しもできます。

プロキシ管理

アカウントごとにプロキシを割り当て。まとめて適用したり、未設定のアカウントをひと目で確認できます。

アカウントチェック

ログイン切れ・ロック・凍結をまとめて確認。状態が変わったアカウントはすぐに通知します。

まとめて操作

選んだアカウントでいっせいに実行。テンプレートを使えば、文面の使い回しもかんたん。

  • 一括投稿
  • 一括フォロー
  • 相互フォロー
  • いいね・リポスト
  • プロフィール変更

DM 自動返信

届いた DM に、設定したメッセージで自動返信。アカウントごとに ON / OFF を切り替えられます。

面倒な設定も一括で

メールアドレスの変更、表示言語の設定、凍結解除の申請も、まとめて進められます。

自動アップデート

新しいバージョンが出るとアプリ内でお知らせ。いつでも最新の機能を使えます。

データはあなたの PC に

アカウント情報はお使いの PC の中だけに保存。私たちのサーバーに送られることはありません。

Use cases

こんな使い方ができます

アカウントの数や目的に合わせて、運用をまとめられます。

アフィリエイト・ジャンル運用

ジャンルごとのアカウントを、グループで切り替え

ジャンル別にグループを作り、投稿はテンプレートから一括で。ログイン切れや凍結はアカウントチェックでまとめて確認できます。

店舗・ブランド運用

店舗アカウントとキャンペーン用を、ひとつの画面で

店舗ごとのアカウントを並べて管理。DM には自動返信を設定して、返信漏れを防げます。

運用代行・チーム

預かったアカウントを、ログアウトせずに管理

アカウントごとに独立したブラウザとプロキシで、ログイン状態を保ったまま担当アカウントを行き来できます。

FAQ

よくある質問

動作環境を教えてください

Mac は Apple シリコン（M1 以降）、Windows は Windows 10 / 11（64bit）に対応しています。アカウントチェック機能には Google Chrome（Windows では Microsoft Edge でも可）を使います。

何台のパソコンで使えますか？

1つのライセンスで2台まで使えます。パソコンを買い替えるときは、アプリの「アプリ設定」→「ライセンス解除」をしてから、新しいパソコンで認証してください。

解約はいつでもできますか？

はい、購入完了メールのリンク（My Orders）からいつでも解約できます。解約後も、支払い済みの期間が終わるまではご利用いただけます。

Mac で「開けません」と表示されます

「システム設定」→「プライバシーとセキュリティ」を開き、画面下の方にある YamaDeck の「このまま開く」を押してください。初回だけの操作です。

Windows で「PC が保護されました」と表示されます

表示された画面の「詳細情報」を押し、「実行」を選んでください。初回だけの操作です。

アカウントのデータはどこに保存されますか？

お使いのパソコンの中だけに保存されます。ライセンスの確認とアップデートの確認以外で、外部と通信することはありません。

使い方がわからないときや、不具合のときは？

公式 Discord の「質問」「不具合報告」フォーラムで受け付けています。アップデートのお知らせもここで配信しています。公式 Discord に参加する

アカウントが凍結されることはありませんか？

YamaDeck はアカウントの管理と操作を効率化するツールで、凍結されないことを保証するものではありません。X の利用規約やルールに沿った運用をお願いします。
